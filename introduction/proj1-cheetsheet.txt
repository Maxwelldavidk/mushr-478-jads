Q2.3 find topic/type:
Start simulator, then in another sourced terminal:
rostopic list
rostopic info /car/car_pose

Known answers:
- Topic: /car/car_pose
- Type: geometry_msgs/PoseStamped

Import:
from geometry_msgs.msg import PoseStamped

Subscriber line:
self.subscriber = rospy.Subscriber("/car/car_pose", PoseStamped, self.callback)

Q2.4 test:
rostest introduction pose_listener.test

Q2.5 step order:
1. Start teleop with sandbox map:
roslaunch cse478 teleop.launch map:='$(find mushr_sim)/maps/sandbox.yaml'

2. In another sourced shell, run path publisher with a plan file:
roslaunch introduction path_publisher.launch plan_file:='$(find introduction)/plans/figure_8.txt'

3. Open RViz if you want to watch:
rosrun rviz rviz -d ~/mushr_ws/src/mushr478/cse478/config/default.rviz

4. Run again with:
roslaunch introduction path_publisher.launch plan_file:='$(find introduction)/plans/tight_figure_8.txt'
